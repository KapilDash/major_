## 🎯 **How to Use**

### **1. Chatbot - Answer ANY Question**

**Before:** Chatbot only answered predefined questions
```
Q: "What is the difference between FIR and bail application?"
A: "I don't have that information" ❌
```

**Now:** Asks Google Gemini API ✅
```
Q: "What is the difference between FIR and bail application?"
A: "FIR is a formal police complaint under CrPC Section 154, while bail 
   is a court procedure under CrPC Section 437-439. Let me explain..." ✅
```

**How it works:**
1. Type any legal question in the Chatbot page
2. Backend calls Google Gemini API with proper legal context
3. Get accurate legal information with citations

## 📊 **Dataset Information**

### Your CSV Dataset:
- **File:** `datasets/judicial_delay_dataset.csv`
- **Rows:** 1000+ judicial cases
- **Columns:**
  - `case_type`: Criminal, Civil, Family, Commercial, Property
  - `filing_year`: 2010-2023
  - `state`: Indian states where cases filed
  - `court_level`: Supreme, High, District
  - `number_of_hearings`: 4-37 hearings
  - `judge_workload`: 200-700 cases per judge
  - `historical_disposal_rate`: 0.30-0.88 (30%-88%)
  - `delay_months`: 18-50 months average delay

### Data Processing:
- CSV automatically loaded when backend starts
- Converted to structured case precedent data
- Used for all graph and search queries
- Statistics calculated and available via API

## 🐛 **Troubleshooting**

### "PDF generation not available"
```
Error: PDF generation not available. Install reportlab: pip install reportlab
```
**Fix:**
```bash
cd d:\Major_project\backend
pip install reportlab
```

### "No cases found in precedent search"
```
{total_found: 0, similar_cases: []}
```
**Fix:**
- Make sure CSV file exists at `d:\Major_project\datasets\judicial_delay_dataset.csv`
- Restart backend: `python run.py`
- Check backend console for errors

### "Chatbot uses mock responses only"
```
{source: "Legal Knowledge Base (Mock)", status: "fallback"}
```
**Fix:**
- Set `GOOGLE_API_KEY` in `.env`
- Restart backend
- Check API key is valid at https://ai.google.dev/

### "Large CSV takes time to load"
- Normal! First startup loads and processes 1000+ cases
- Takes 5-10 seconds on first load
- Subsequent requests are instant

## 📝 **API Endpoints Reference**

### Precedent Graph (with real data)
```
POST /api/precedent/search
{
  "query": "Criminal",
  "case_type": "Criminal"
}
Returns: [200+ criminal cases from dataset]
```

### Chatbot (with real Google API)
```
POST /api/chatbot/ask
{
  "message": "Your legal question",
  "context": null
}
Returns: Google Gemini answer or fallback response
```

### Drafting with PDF
```
POST /api/drafting/generate-pdf
{
  "case_facts": "Case details...",
  "document_type": "petition"
}
Returns: PDF file as base64 encoded string
```
